INDIVIDUAL CASE STUDY / BUILD 2

PostgreSQL docs assistant

A small source-first tool for questions about importing data and storing JSON.

Try the hosted assistant

The user need

A student importing a laptop CSV into a remote database needs to know which process reads the file. The PostgreSQL manual distinguishes client-side psql \copy from SQL COPY with a filename. The app exposes the relevant paragraphs and their source links.

What works

Import selected permitted snapshots, submit a question, view an extractive answer, and inspect ranked passages, source metadata, and the stored representation. The source set contains 15 paragraphs from three PostgreSQL 18 manual pages.

Research and implementation choice

Review 1 proposed learned embeddings with exact pgvector search, and compared graph traversal. This first build uses exact cosine ranking over sparse TF-IDF vectors, with a small disclosed vocabulary expansion, and composes answers from retrieved paragraphs. SQLite stores content and provenance. This keeps the demo within the existing small server and requires no provider key.

pgvector’s exact-search baseline remains the planned model-backed direction. Graph relationships would add entity and edge validation for this narrow corpus; that alternative remains deferred.

Known limits / unfinished

This is an extractive retrieval prototype, not a completed generative RAG system. It does not call an LLM, use learned embeddings, or run PostgreSQL/pgvector. Lexical overlap can miss paraphrases or return relevant text that does not answer the question. A topic guard and score threshold decline some unsupported questions; neither proves answerability. No arbitrary URL or private-file import is offered.

Contribution and evidence

The existing plan and bookstore foundation predate this build. Shiv requested the individual scope, preservation of existing projects, and honest evidence. Codex implemented the new routes, importer, UI, deployment bundle, and checks. Independent student testing and explanation of this build remain pending.
